Project Title:
​​Event Flow (Multi Role Event and Venue Management System)
Problem Statement:
The events and venue management industry is highly fragmented, with organisers, venue owners, attendees, and administrators working in isolated systems with poor coordination. Organisers rely on manual methods like calls and emails and cannot easily detect scheduling conflicts, while venue owners lack a central platform to showcase spaces, manage bookings, payments, and communication. Attendees face difficulty discovering events, tracking their registrations, and avoiding overlapping bookings. Administrators, on the other hand, have no unified system to monitor activities or resolve issues, and important data is scattered across different tools, making reporting inefficient. Therefore, there is a strong need for a unified web platform that integrates all stakeholders into a single system with role-based access and streamlined management.
Proposed Solution:
How Event Flow System Solves this problem.
• Organiser event conflicts: Detects overlapping events on the server side and prevents scheduling clashes, while showing conflict alerts on the dashboard.
• Venue discovery: Provides a live search system where organisers can filter venues by capacity, date/time, and location, with details like amenities and pricing and quick booking options.
• Attendee double-booking: Identifies schedule conflicts before registration and prompts users to resolve them.
• Registration visibility: Keeps registration data unified so organisers can view attendee details in real time and attendees can track their schedules and history.
• Venue owner bookings: Manages the full booking lifecycle (request, approval/rejection, payment, cancellation) with built-in communication tools.
• Admin oversight: Offers a central dashboard where admins can monitor and manage all users, events, bookings, and venues from one place.
Introduction and Objectives:
Event Flow is a full-featured multi-role event and venue management. It is designed to serve four distinct user personas : Super Admins, Organisers, Venue Owners (referred to internally as Staff), and Attendees, each accessing a customised dashboard tailored to their specific responsibilities.
Core Objectives
● Provide organisers with a rich event creation, management, and analytics toolset.
● Give venue owners a complete building and room management suite including availability calendars, pricing, booking workflows, and document storage.
● Offer attendees a discovery-first experience with smart filtering, an interactive map, a registration calendar, and conflict detection.
● Equip super admins with a god-mode oversight panel spanning all users, events, bookings, and venues.
● Unify all registration data so that organiser and attendee dashboards share the same real-time state.
● Enforce role-based access control so that no user can access another role's data or actions.
Design Philosophy
Event Flow follows a minimal, professional aesthetic throughout:
● Background: #FAFAFA (warm off-white)
● Cards: #FFFFFF with #E8E8E8 borders and 2–4 px box shadows
● Primary text: #1A1A1A, Secondary text: #6B6B6B
● Accent colour: #2D2D2D, used consistently for CTAs and active states
● No third-party design libraries — all UI is built with Flutter Material widgets tuned to match the palette
 
Key Modules & Features
1. Organiser Dashboard (4 Tabs)
The Organiser Dashboard provides tools for creating, managing, and analysing events efficiently.
a) Events Tab
Displays real-time statistics including total events, upcoming events, drafts, and completed events.
Detects scheduling conflicts by identifying overlapping event timings and highlights them with a “Time Conflict” badge along with a summary warning banner.
Each event card shows important details such as category, status (Upcoming, Ongoing, Completed, Draft), date & time, venue location, and registered vs expected attendees.
Provides event management actions including edit, duplicate, delete, book venue, and cancel booking.
Includes an event creation/editing form with fields for title, description, category, expected attendees, and date-time selection, with options to save as draft or publish.
Displays a warning when editing events that already have active bookings.
b) Attendees Tab
Allows organisers to select any of their published events using a dropdown menu.
Shows a summary of total registered and attended participants.
Displays attendee details such as name, email, registration date, and notes.
Enables organisers to mark attendance, which updates instantly across the system via the shared RegistrationService.
c) Venues Tab
Provides advanced filtering options including date/time range, capacity, and location.
Uses a search function to find available venues based on time availability, capacity, and location.
Displays venue details such as room name, building, address, pricing, and amenities.
Allows organisers to instantly book a venue for any unbooked event with a single action.
d) Analytics Tab
Displays key performance indicators including total registrations, fill rate, and best-performing event.
Visualises data using bar charts comparing registered vs expected attendees.
Provides detailed per-event analysis with progress indicators and attendance statistics.
 
2. Venue Owner (Staff) Dashboard
This module enables venue owners to manage buildings, rooms, and bookings.
a) Building Management
Allows creation, editing, and deletion of buildings with details such as name, address, city, and description.
Integrates an interactive map for selecting building location.
Displays building summaries including room count and location.
Supports proximity-based search using geographic calculations.
b) Room Management
Enables creation and management of rooms linked to buildings.
Defines room attributes such as type, capacity, and amenities.
Provides pricing configuration including hourly rates and booking rules.
Manages availability schedules with validation to prevent overlaps.
c) Booking Workflow
Handles booking requests submitted by organisers.
Allows venue owners to approve, reject, or request changes.
Includes in-app communication between organisers and venue owners.
Tracks payment status including pending, completed, and refunded transactions.
d) Documents Management
Allows uploading and categorisation of important documents such as licenses and certificates.
Displays document details including upload date, owner, and notes.
3. Attendee Dashboard (5 Tabs)
The Attendee Dashboard focuses on event discovery and participation.
Events Tab: Enables users to search and filter events, view details, and register while preventing scheduling conflicts.
Calendar Tab: Displays registered events in a monthly calendar view for easy tracking.
Map Tab: Shows event locations on an interactive map, allowing users to explore and register.
Alerts Tab: Provides notifications such as confirmations, reminders, and cancellations.
Analytics Tab: Displays personal insights including total events attended, categories, and upcoming events.
Registration Flow: Users must log in before registering. If a scheduling conflict is detected, a confirmation dialog is shown to prevent double booking.
4. Super Admin Dashboard
The Super Admin Dashboard provides full system control and monitoring capabilities.
Users Panel: Manage user accounts, roles, and access status.
Events Panel: View all events across the platform.
Bookings Panel: Monitor all booking activities and statuses.
Venues Panel: Access all buildings and rooms managed by venue owners.
Analytics: View overall platform statistics including total users, events, bookings, and revenue.
